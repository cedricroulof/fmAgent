# fmagent

A terminal assistant for Apple's on-device Foundation Model. Unlike `fm`, it can run commands and read and edit files, and it asks before each command or change.

```sh
npm install -g fmagent
fmagent
```

**Requirements:** a Mac with Apple Silicon, macOS 26 or later, and Apple Intelligence turned on (System Settings → Apple Intelligence & Siri). Node is used only to install the program, which is a native binary.

Commands, tools, limits and how it handles your data: see the [full README](https://github.com/cedricroulof/fmAgent#readme).
